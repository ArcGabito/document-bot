# DocumentBot

Bot RPA de **gestión documental** (IDP): captura contratos, órdenes de compra, guías de remisión, DNI y otros documentos; los clasifica y extrae con OCR e IA, los archiva en expedientes con permisos y retención, avisa vencimientos y genera documentos desde plantillas.

Stack: **Python 3.13 + uv · FastAPI · SQL Server / Azure SQL · Redis · colas (Dramatiq) · Docker**, desplegable en un VPS (Docker Compose) o en Azure Container Apps.

> **Estado**: en desarrollo. El plan por fases está en [ROADMAP.md](ROADMAP.md).
